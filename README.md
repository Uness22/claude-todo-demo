# المعمل الافتراضي لميكروبيولوجيا الغذاء 🔬

موقع تعليمي عربي (RTL) يحاكي **معمل ميكروبيولوجيا غذاء كامل التجهيز** لطلبة علوم الأغذية الذين
لم يتمكّنوا من حضور الجلسات العملية. كل شيء يعمل **دون إنترنت** ودون أي مكتبة خارجية:
موقع ثابت (HTML + CSS + JS) بمحرّك رسم حقيقي على Canvas، ولا يحتاج إلا إلى متصفح.

```
افتح index.html مباشرة في المتصفح، أو شغّل خادمًا محليًا:
    python3 -m http.server 8000        ثم افتح  http://localhost:8000
```

> **تريد تنزيله وتشغيله على جهازك الآن؟** اقرأ **[START-HERE.md](START-HERE.md)** — طريقة التحميل من GitHub والتشغيل والاستوديو الصوتي في خطوات.

## مفاهيم مُحاكاة بدقّة علمية

* **البصريات**: NA للعدسات (0.10/0.25/0.65/1.25)، عمق ميدان يضيق مع التكبير، إضاءة Köhler غير مثالية (بقع ضوء)، غبار العدسة، توهّج خلفية عند غياب زيت الغمر، هالات انكسار حول الخلايا.
* **المقاسات**: مجال الرؤية بوحدات حقيقية (1000 وحدة عند 100× × 0.18 µm = 180 µm قطرًا) وسلّم قياس متحرّك؛ الخلايا أصغر من بكسل تُرسم كنقاط صبغية في مواضعها الحقيقية.
* **العدّ**: توزيع Poisson على الأطباق، نطاق معدود 30–300 CFU، `CFU/غ = المستعمرات ÷ (الحجم × التخفيف)`.
* **القتل الحراري**: D-value = زمن إنقاص لوغاريتم واحد، وسلوك لوغاريتمي خطي.
* **الأوساط**: ألوان القراءة الحقيقية (MacConkey وردي=مخمّر لاكتوز، XLD أحمر بمركز أسود=سالمونيلا H₂S⁺، MSA أصفر=مانيتول ⁺…).

## البنية

```
*.html                13 صفحة (كل صفحة مستقلّة، وفيها روابط تنقّل موحّدة)
assets/css/lab.css    نظام التصميم الكامل (داكن مختبري + طباعة + RTL)
assets/js/core.js     الهيكل: التنقّل، التخزين، XP والشارات، الدفتر، النوافذ، محرّك الاختبارات
assets/js/microbes.js مكتبة أشكال الميكروبات (30 شكلًا) SVG + Canvas بالعربية
assets/js/microscope.js محرّك المجهر الافتراضي (35 شريحة، عدسات، بلاطات، حركة)
assets/js/data.js     قاعدة المعرفة: الميكروبات، الأوساط، الفيديوهات، الجلسات، الأسئلة، الحدود
assets/js/pages.js    مكوّنات مشتركة: خريطة المعمل، البطاقات، الموسوعة، الجلسات، الدفتر، الأنيميشن
assets/js/labs-*.js   محاكيات: bench / gram / dilution / media / instruments
tests/headless.js     اختبار آلي لكل الصفحات (jsdom) — اختياري
```

### تشغيل الاختبار الآلي (اختياري، للتطوير فقط)

```bash
npm install jsdom          # أداة تطوير فقط، لا تدخل في الموقع
node tests/headless.js     # 13 صفحة + 12 سيناريو تفاعلي (نقرات على كل محاكي)
node tests/headless.js --boot   # فحص التحميل فقط
```

## التخزين والخصوصية

كل شيء محلي في المتصفح (`localStorage` بمفاتيح `vlab.`) — لا حساب، لا سيرفر، ولا إرسال بيانات.
🖨 يمكن طباعة الدفتر والتقرير والشهادة (تنسيق طباعة مخصّص داخل `lab.css`).
