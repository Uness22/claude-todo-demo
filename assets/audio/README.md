# مقاطع التعليق الصوتي (assets/audio)

**المتوفر الآن:** 5 مقاطع عربية + 5 مقاطع إنجليزية (راوٍ مختار) لوحدات:
الجولة الافتتاحية `tour` · صبغة جرام `gram` · الزرع والعزل `bench` ·
التخفيف والعدّ `dilution` · المجهر `microscope`.


التعليق الصوتي في الاستوديو يعمل على مستويين:

1. **نصوص منطوقة عبر صوت المتصفح** (Web Speech) — تعمل بلا أي ملفات، لكل الصفحات
   وكل خطوة عملية، بالعربية والإنجليزية (مفاتيح التعليق في `assets/js/studio.js`).
2. **مقاطع مسجّلة مضمّنة** — تُستخدم تلقائيًا إن وُجد الملف، وإلا يعود الاستوديو
   إلى صوت المتصفح. المسارات المتوقّعة:

```
assets/audio/ar/<slug>.mp3      # التسجيل العربي
assets/audio/en/<slug>.mp3      # التسجيل الإنجليزي
```

والمفاتيح المعرَّفة حاليًا في `studio.js` (ثابت `CLIPS`):

| الصفحة | Slug |
|---|---|
| index.html | `tour` |
| gram.html | `gram` |
| bench.html | `bench` |
| dilution.html | `dilution` |
| microscope.html | `microscope` |

لتسجيل وحدة جديدة: أضف مفتاحًا في `CLIPS` باسم الصفحة واسم الملف، ثم ضع الملفات في
`assets/audio/ar` و `assets/audio/en`. الترميز المقترح: MP3 بمعدل 96–128 كيلوبت/ث
(أحجام صغيرة تعمل دون إنترنت).
